# M1 继承约束与验收任务

本清单登记后续验收，不属于 M0 实现范围；**进入 M1 仍需用户明确批准**。M0 每会话一个原生 worker、Shell 创建前绑定会话 Job、固定进程句柄确认真实退出码、按 PID + 创建时间清理的已验证基线应保留，不未经证据改回共享原生进程。

| M1 任务 | 必须观察的验收行为 |
|---|---|
| 长日志有界背压与可靠尾输出排空 | 持续高输出下队列与内存有界，UI 不因堆积失控；关闭/自然退出能可靠排空尾输出，不能以 M0 短等待或一个标记成功替代 |
| 已结束会话、进程句柄与监听器及时释放 | 自然退出和关闭后按留存策略释放注册表、ProcessHandle、worker/IPC/xterm 监听器；反复创建关闭后资源不持续增长 |
| 中文输入法、Ctrl+C、全屏终端程序 | 真实 IME 组合输入不丢失/误提交，控制信号可观察，全屏程序 resize、退出和恢复正常；逐 Shell 记录范围 |
| 递归分屏、焦点与终端尺寸联动 | pane/session/terminal 标识归属清晰，多层拖拽、关闭、最大化及辅助栏开合后焦点与 PTY 尺寸正确，其他会话不受影响 |
| 页面和 xterm 同源主题 | 唯一 palette 同时生成页面 token 与 xterm theme；system/light/dark 组合及系统切换一致，canvas 不遗留旧色 |
| 生产 IPC 权限与输入校验 | sender/frame/会话归属、schema、generation、尺寸、字节限制、路径/权限边界与负面用例齐备；M0 白名单不能直接当生产安全结论 |

另需后续量测 worker CPU/内存和启动成本、长时稳定性、其他 Shell/机器/Windows 版本、字体与缩放、签名安装器和全部传递依赖分发许可；本轮不编造性能数字或跨机器保证。

M0 收尾的通过只是可以提交 M1 放行建议，不自动代表 M1 开发授权或上述项目已完成。
